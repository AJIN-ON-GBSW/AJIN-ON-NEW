## 실제 브라우저 확인

- 원본 HTML과 홈 화면을 비교하고 메뉴·배너·전체 보기 동작을 확인했습니다. 원본과 앱 브라우저의 뷰포트 크기가 달라 픽셀 단위 동일성 수치는 산출하지 않았습니다.
- 모든 8개 화면에 진입하고 현장평가 기준 펼치기, 내부평가 차수·달력 전환, SQ 업종 필터, IATF 심사 종류 필터를 확인했습니다.
- 실적에 입고 1000개·국내 불량 2개·KD 불량 1개를 입력해 PPM 3000.00을 확인했습니다. 저장 후 새로고침해도 값이 유지됐습니다.
- 품질경영 9.5점과 메모를 저장하고 품질5스타의 품질경영 9.50점·총점 88.56점 연결 및 중간 집계 기록 저장을 확인했습니다.
- 브라우저에서 실제 XLSX를 내려받았습니다. 첨부 파일도 브라우저로 업로드·다운로드하고 원본 바이트가 같은지 확인했습니다.
- 11열 XLSX에 내부평가·IATF 두 행을 넣어 미리보기 → PostgreSQL 등록 → 새로고침 → 종류·공장 필터 → 실제 부적합·개선대책 상세 표시를 확인했습니다.
- 동일 XLSX를 다시 등록하면 새 등록 0건·중복 2건으로 표시됐습니다. 공장 필터로 내려받은 실제 XLSX는 제목 1행과 해당 데이터 1행이며 원문을 보존했습니다.
- 서비스 재시작과 실행 스크립트의 중복 실행을 점검했습니다. DB 볼륨과 저장 상태는 유지됩니다.

검증에 사용한 입력값·점수·스냅샷·가져온 행·첨부 파일은 해당 테스트 식별자만 확인해 정리했습니다. 원본 초기 데이터와 다른 기록은 유지했습니다.

## 원본에 따른 범위

원본의 4,895개 세부 행과 132개 평가 회차를 보존합니다. 원본의 일부 요약 집계와 세부 행 수가 일치하지 않아 목록·내보내기 건수는 실제 출력되는 세부 행을 기준으로 통일했습니다. 원본에 있는 분석·기준표는 제공된 데이터로 표시하고, 새로 가져온 행은 목록·검색·필터·XLSX에 반영합니다.

원본에 없는 부적합 본문, 점수, 공식 환산표, 평가원 정보를 만들어 넣지 않았습니다. 준비 중 AI 메뉴, 미제공 메뉴 페이지, PDF 평가서의 자동 문항 추출은 추가 개발 범위입니다. 자료 첨부·보관은 동작합니다. 관리자 전환은 편집 모드이며 사용자 인증·권한 시스템은 포함하지 않습니다. 외부 서버 배포 검증은 이번 새 프로젝트 작업에 포함하지 않았습니다.
